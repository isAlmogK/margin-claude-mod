# margin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `margin`, a Claude Code mod that redraws Claude's replies for the VS Code side panel, pins the things worth keeping per project, and searches the current chat.

**Architecture:** One hooks module (`hooks/register.tsx`) wires small files that each do one job. Pure files (`secrets`, `blocks`, `keep`, `search`) hold all the parsing and matching and are unit tested directly. Engine-facing files (`pins`, `settings`, `note`, `reply`, `turn`, `pane`, `commands`) hook `session.start`, `prompt.compose`, `ui.render`, `turn.complete`, `prompt.submit` and `command.run`, keep drawn values in `$.state` atoms, and persist pins and settings in `$.store`.

**Tech Stack:** TypeScript + JSX against the `claude-code` mod API of Claude Code 2.1.309; tests with `claude-code/testing` run by `claude plugin test`; `claude plugin validate`; `tsc` 5.6.

**Spec:** [docs/superpowers/specs/2026-10-27-margin-design.md](../specs/2026-10-27-margin-design.md)

## Global Constraints

- Mod name `margin`, version `0.1.0`, license MIT, repository `isAlmogK/claude-margin`, install line `/plugin install margin --marketplace isAlmogK/claude-margin`.
- Work on the branch `feat/margin-0.1`, never on `main`. Conventional commit messages, each ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Built and checked against Claude Code `2.1.309` (`claude --version`).
- The API types for this build are at `<plugin-authoring skill folder>/types/claude-code.d.ts`. If that path is gone (a new session), load the `plugin-authoring` skill again and use the path it names. Grep it for any name you are unsure of; it is the authority.
- Hooks modules have no DOM and no Node: no `console`, no `Date.now()` (use `await $.clock.now()`), no `setTimeout`, no `import()`. Everything outside the module goes through `$`.
- Every value a drawing reads lives in a `$.state` atom declared in `hooks/state.ts` and in the contract `types/index.d.ts`. Never a module variable: a hot reload resets them, and `$.ui.invalidate` does not redraw panes.
- Colours are theme keys only: `text`, `subtle`, `success`, `warning`, `claude`.
- `claude plugin test .` runs every `*.test.ts(x)` file; there is no single-file filter. "Expected: FAIL" in a step means the new test fails and the earlier ones still pass.
- Type-check with `npx -y -p typescript@5.6.3 tsc -p .` after copying the types in (Task 1, Step 2).
- User-facing words: sentence case, plain, no "successfully", no exclamation marks.
- The note to Claude is the exact `NOTE` text in Task 6.

import type { TestBody } from 'claude-code/testing'

type TestEngine = Parameters<TestBody>[0]
type TestOn = Parameters<TestBody>[1]

export const PROJECT = '/work/my-app'
export const SURFACES = ['vscode', 'desktop', 'terminal', 'mobile'] as const

export type ChatRow = { role: 'user' | 'assistant'; text: string; toolUses: [] }

export type Fake = {
  store: Map<string, unknown>
  copied: string[]
  opened: string[]
  toasts: string[]
  commands: string[]
  messages: ChatRow[]
  now: { value: number }
}

// Stands in for the engine beneath the plugin: every `$` call margin makes is answered here.
export const fakeEngine = (on: TestOn, options: { isStoreDown?: boolean } = {}): Fake => {
  const fake: Fake = { store: new Map(), copied: [], opened: [], toasts: [], commands: [], messages: [], now: { value: 1_000_000 } }
  on('store.get', (_, e) => {
    if (options.isStoreDown) throw new Error('store down')
    return { value: fake.store.get(e.key) }
  })
  on('store.set', (_, e) => {
    if (options.isStoreDown) throw new Error('store down')
    fake.store.set(e.key, e.value)
    return { value: undefined }
  })
  on('clock.now', () => ({ value: fake.now.value }))
  on('session.id', () => ({ value: 'chat-1' }))
  on('session.messages', () => ({ value: fake.messages }))
  on('ui.open', (_, e) => {
    fake.opened.push(e.id)
    return { value: { isPlaced: true } }
  })
  on('ui.copy', (_, e) => {
    fake.copied.push(e.text)
    return { value: { isCopied: true } }
  })
  on('ui.toast', (_, e) => {
    fake.toasts.push(e.text)
    return { value: undefined }
  })
  on('command.register', (_, e) => {
    fake.commands.push(e.name)
    return { value: { command: e.name } }
  })
  on('session.start', (_, e) => ({ cwd: e.cwd }))
  on('turn.complete', () => ({ text: '' }))
  on('prompt.submit', (_, e) => ({ text: e.text }))
  on('prompt.compose', () => ({ sections: [{ id: 'intro', text: 'You are Claude Code.', scope: 'shared' as const }] }))
  return fake
}

export const startSession = ($: TestEngine, surface: (typeof SURFACES)[number] = 'vscode') =>

export const finishTurn = ($: TestEngine, answer: string, extra: { agentId?: string; isAborted?: boolean } = {}) =>

  $.prompt.compose({ model: 'claude-opus-5-5', promptModel: 'claude-opus-5-5', surfaces: ['vscode'], tools: [], outputStyle: null, traits: [] })

`hooks/secrets.ts`:

```ts
const PATTERNS: readonly RegExp[] = [
  /\bsk-ant-[A-Za-z0-9_-]{20,}/,
  /\bsk-[A-Za-z0-9_-]{20,}/,
  /\bgh[pousr]_[A-Za-z0-9]{30,}/,
  /\bgithub_pat_[A-Za-z0-9_]{40,}/,
  /\bAKIA[0-9A-Z]{16}\b/,
  /\bxox[abps]-[A-Za-z0-9-]{10,}/,
  /\beyJ[A-Za-z0-9_-]{8,}\.[A-Za-z0-9_-]{8,}\.[A-Za-z0-9_-]{8,}/,
  /-----BEGIN [A-Z ]*PRIVATE KEY-----/,
]

const TOKEN_CHARS = /^[A-Za-z0-9+/=_-]+$/

// Shannon entropy in bits per character.
export const entropy = (text: string): number => {
  const counts = new Map<string, number>()
  for (const char of text) counts.set(char, (counts.get(char) ?? 0) + 1)
  let bits = 0
  for (const count of counts.values()) {
    const share = count / text.length
    bits -= share * Math.log2(share)
  }
  return bits
}

export const isSecret = (value: string): boolean =>
  PATTERNS.some(pattern => pattern.test(value)) ||
  value.split(/\s+/).some(word => word.length >= 32 && TOKEN_CHARS.test(word) && entropy(word) >= 4)
```

````ts
export type Point = { text: string; isDownside: boolean }
export type Option = { title: string; subtitle: string; isLean: boolean; points: Point[] }

export type Block =
  | { kind: 'lead' | 'paragraph' | 'label' | 'ask' | 'pending'; text: string }
  | { kind: 'list'; items: string[]; isOrdered: boolean }
  | { kind: 'code'; language: string; source: string }
  | { kind: 'options'; options: Option[] }
  | { kind: 'keep'; lines: string[] }
  | { kind: 'other'; markdown: string }

const FENCE_OPEN = /^```([\w-]*)\s*$/
const FENCE_CLOSE = /^```\s*$/
const HEADING = /^#{1,6}\s+(.*)$/
const LIST_ITEM = /^(\s*)([-*+]|\d+[.)])\s+(.*)$/
const CONTINUATION = /^\s{2,}\S/
const OTHER_LINE = /^\s*[|<>]/
const LEAD_MAX = 200

export const readOptions = (body: readonly string[]): Option[] | null => {
  const groups: string[][] = [[]]
  for (const line of body) {
    if (line.trim() === '') {
      if ((groups.at(-1) ?? []).length > 0) groups.push([])
      continue
    }
    groups.at(-1)?.push(line.trim())
  }
  const filled = groups.filter(group => group.length > 0)
  if (filled.length === 0 || filled.length > 3) return null

  const options: Option[] = []
  for (const [head = '', ...rest] of filled) {
    const parts = head.split('|').map(part => part.trim())
    const title = parts[0] ?? ''
    if (title === '' || /^[+-]\s/.test(head)) return null
    const points: Point[] = []
    for (const line of rest) {
      const point = /^([+-])\s+(.*)$/.exec(line)
      if (!point) return null
      points.push({ text: point[2] ?? '', isDownside: point[1] === '-' })
    }
    options.push({ title, subtitle: parts[1] ?? '', isLean: parts.slice(2).some(part => part.toLowerCase() === 'lean'), points })
  }
  return options
}

const fenced = (language: string, body: readonly string[], raw: string): Block => {
  if (language === 'options') {
    const options = readOptions(body)
    return options ? { kind: 'options', options } : { kind: 'other', markdown: raw }
  }
  if (language === 'ask') return { kind: 'ask', text: body.join(' ').trim() }
  if (language === 'keep') return { kind: 'keep', lines: body.map(line => line.trim()).filter(line => line !== '') }
  return { kind: 'code', language, source: body.join('\n') }
}

const list = (rows: readonly string[]): Block => {
  const entries: { indent: number; text: string; marker: string }[] = []
  for (const row of rows) {
    const item = LIST_ITEM.exec(row)
    if (item) {
      entries.push({ indent: (item[1] ?? '').length, text: item[3] ?? '', marker: item[2] ?? '' })
      continue
    }
    const last = entries.at(-1)
    if (last) last.text = `${last.text} ${row.trim()}`
  }
  const levels = [...new Set(entries.map(entry => entry.indent))].sort((a, b) => a - b)
  if (levels.length > 2) return { kind: 'other', markdown: rows.join('\n') }
  const top = levels[0] ?? 0
  return {
    kind: 'list',
    items: entries.map(entry => (entry.indent > top ? `  ${entry.text}` : entry.text)),
    isOrdered: /\d/.test(entries[0]?.marker ?? ''),
  }
}

export const readBlocks = (markdown: string, isFirstOfReply: boolean): Block[] => {
  const lines = markdown.split('\n')
  const blocks: Block[] = []
  let paragraph: string[] = []
  const flush = (): void => {
    if (paragraph.length > 0) blocks.push({ kind: 'paragraph', text: paragraph.join(' ') })
    paragraph = []
  }

  let at = 0
  while (at < lines.length) {
    const line = lines[at] ?? ''
    const fence = FENCE_OPEN.exec(line)
    if (fence) {
      flush()
      const end = lines.findIndex((row, index) => index > at && FENCE_CLOSE.test(row))
      if (end === -1) {
        blocks.push({ kind: 'pending', text: lines.slice(at).join('\n') })
        break
      }
      blocks.push(fenced(fence[1] ?? '', lines.slice(at + 1, end), lines.slice(at, end + 1).join('\n')))
      at = end + 1
      continue
    }
    if (line.trim() === '') {
      flush()
      at += 1
      continue
    }
    const heading = HEADING.exec(line)
    if (heading) {
      flush()
      blocks.push({ kind: 'label', text: (heading[1] ?? '').trim() })
      at += 1
      continue
    }
    if (LIST_ITEM.test(line)) {
      flush()
      const start = at
      while (at < lines.length && (LIST_ITEM.test(lines[at] ?? '') || CONTINUATION.test(lines[at] ?? ''))) at += 1
      blocks.push(list(lines.slice(start, at)))
      continue
    }
    if (OTHER_LINE.test(line)) {
      flush()
      const start = at
      while (at < lines.length && (lines[at] ?? '').trim() !== '' && !FENCE_OPEN.test(lines[at] ?? '')) at += 1
      blocks.push({ kind: 'other', markdown: lines.slice(start, at).join('\n') })
      continue
    }
    paragraph.push(line.trim())
    at += 1
  }
  flush()

  const first = blocks[0]
  if (isFirstOfReply && first?.kind === 'paragraph' && first.text.length <= LEAD_MAX) blocks[0] = { kind: 'lead', text: first.text }
  return blocks
}
````

import type { MarginKeepItem } from '../types'
import { readBlocks } from './blocks'
import { isSecret } from './secrets'

export const KEEP_MAX = 6

const LINE = /^([^:]{1,24}):\s+(.+)$/
const APP_URL = /\bhttps?:\/\/(?:localhost|127\.0\.0\.1|0\.0\.0\.0):\d+[^\s)`'"]*/
const PASSWORD = /\bpassword\b[\s:]*(?:is\s+)?`?([^\s`'",.)]+)`?/i
const VALUE_LIKE = /[\d_-]/

const unticked = (value: string): string => value.replace(/^`(.*)`$/, '$1')

export const fromKeepLines = (lines: readonly string[]): MarginKeepItem[] =>
  lines
    .map(line => LINE.exec(line.trim()))
    .filter(match => match !== null)
    .map(match => ({ label: (match[1] ?? '').trim(), value: unticked((match[2] ?? '').trim()), source: 'claude' as const }))
    .slice(0, KEEP_MAX)

export const fromPatterns = (text: string): MarginKeepItem[] => {
  const items: MarginKeepItem[] = []
  const url = APP_URL.exec(text)
  if (url) items.push({ label: 'App', value: url[0], source: 'pattern' })
  const password = PASSWORD.exec(text)?.[1]
  if (password !== undefined && VALUE_LIKE.test(password)) items.push({ label: 'Password', value: password, source: 'pattern' })
  return items
}

export const findKeep = (answer: string): MarginKeepItem[] => {
  const fences = readBlocks(answer, false).flatMap(block => (block.kind === 'keep' ? [block.lines] : []))
  const items = fences.length > 0 ? fromKeepLines(fences.flat()) : fromPatterns(answer)
  return items.filter(item => !isSecret(item.value))
}

import { read, update } from 'claude-code'

import type { MarginPin } from '../types'
import { isSecret } from './secrets'
import { cwdAtom, type Engine, isStoreDownAtom, pinsAtom } from './state'

export type PinInput = { label: string; value: string; source: MarginPin['source'] }

export const DAY = 24 * 60 * 60 * 1000
export const STORE_DOWN = 'margin: pins are kept for this chat only. Its storage could not be reached.'

export const storeKey = (cwd: string): string => `pins:${cwd}`

export const isLive = (pin: MarginPin, now: number): boolean => pin.expiresAt === null || pin.expiresAt > now

const matchKey = (pin: MarginPin): string => {
  const label = pin.label.toLowerCase()
  return label === 'note' ? `note:${pin.value}` : label
}

// Newest first. A pin with the same match key replaces the old one, keeping its id and,
// if it was kept by hand, its permanence.
export const mergePins = (pins: readonly MarginPin[], incoming: readonly MarginPin[]): MarginPin[] => {
  let merged = [...pins]
  for (const pin of incoming) {
    const old = merged.find(one => matchKey(one) === matchKey(pin))
    const next = old ? { ...pin, id: old.id, expiresAt: old.expiresAt === null ? null : pin.expiresAt } : pin
    merged = [next, ...merged.filter(one => one !== old)]
  }
  return merged
}

let made = 0

export const makePin = (item: PinInput, chat: string, now: number, isLasting: boolean): MarginPin => {
  made += 1
  return {
    id: `${now.toString(36)}-${made.toString(36)}`,
    label: item.label,
    value: item.value,
    secret: item.source === 'user' && isSecret(item.value),
    source: item.source,
    chat,
    createdAt: now,
    expiresAt: isLasting || item.source === 'user' ? null : now + DAY,
  }
}

const storeFailed = async ($: Engine): Promise<void> => {
  if (await read($, isStoreDownAtom)) return
  await update($, isStoreDownAtom, () => true)
  $.ui.toast(STORE_DOWN)
}

const storedPins = async ($: Engine): Promise<MarginPin[] | null> => {
  if (await read($, isStoreDownAtom)) return null
  try {
    const raw = await $.store.get(storeKey(await read($, cwdAtom)))
    return Array.isArray(raw) ? (raw as MarginPin[]) : []
  } catch {
    await storeFailed($)
    return null
  }
}

export const loadPins = async ($: Engine): Promise<void> => {
  const now = await $.clock.now()
  const pins = await storedPins($)
  if (pins !== null) await update($, pinsAtom, () => pins.filter(pin => isLive(pin, now)))
}

// The store is the source of truth, so a save keeps what other chats in the project added.
export const savePins = async ($: Engine, change: (pins: MarginPin[]) => MarginPin[]): Promise<MarginPin[]> => {
  const now = await $.clock.now()
  const base = (await storedPins($)) ?? (await read($, pinsAtom))
  const pins = change(base).filter(pin => isLive(pin, now))
  await update($, pinsAtom, () => pins)
  if (!(await read($, isStoreDownAtom))) {
    try {
      await $.store.set(storeKey(await read($, cwdAtom)), pins)
    } catch {
      await storeFailed($)
    }
  }
  return pins
}

export const addItems = async ($: Engine, items: readonly PinInput[], isLasting: boolean): Promise<MarginPin[]> => {
  const now = await $.clock.now()
  const chat = await $.session.id()
  const incoming = [...items].reverse().map(item => makePin(item, chat, now, isLasting))
  return savePins($, pins => mergePins(pins, incoming))
}
```

`mergePins` puts each incoming pin at the top, so `addItems` feeds them in reverse: a reply's items then sit at the top in the reply's own order (`App, Password, Start, Stop`), above older pins.

export const registerTurn = (on: On): void => {

    if (e.agentId !== undefined || e.isAborted || e.reason !== 'answer') return done

    if (!(await read($, hasPeekedAtom))) {
      await update($, hasPeekedAtom, () => true)
      await update($, isPeekAtom, () => true)
      await update($, isOpenAtom, () => true)
      await $.ui.open({ id: PANE, title: 'Pins' })
    }
    return done
  })
}

```tsx
import { read } from 'claude-code'

import type { Block } from './blocks'
import { readBlocks } from './blocks'
import { fromKeepLines } from './keep'
import { isSecret } from './secrets'
import { isOffAtom, type On } from './state'

export const LINE_MAX = 76
export const WIDE_MIN = 70

const RUN = /(`[^`]+`|\*\*[^*]+\*\*)/

export const registerReply = (on: On): void => {
  on('ui.render', { component: 'AssistantMessage' }, async ($, e, next) => {
    if (e.props.isSummary === true || (await read($, isOffAtom))) return next(e)

    const { Box, Text, Button, Code, Markdown } = $.ui.resolve(e)
    const blocks = readBlocks(e.props.text, e.props.isFirstOfReply)
    const columns = e.viewport?.columns
    const isWide = (columns ?? 0) >= WIDE_MIN

    // Inline code becomes a chip, **bold** stays bold; everything else is plain text.
    const runs = (text: string) =>
      text
        .split(RUN)
        .filter(part => part !== '')
        .map(part =>
          part.length > 2 && part.startsWith('`') && part.endsWith('`') ? (
            <Text color="claude" mono>{part.slice(1, -1)}</Text>
          ) : part.length > 4 && part.startsWith('**') && part.endsWith('**') ? (
            <Text weight="semibold">{part.slice(2, -2)}</Text>
          ) : (
            part
          ),
        )

    const keep = blocks
      .flatMap(block => (block.kind === 'keep' ? fromKeepLines(block.lines) : []))
      .filter(item => !isSecret(item.value))

    const draw = (block: Block) => {
      switch (block.kind) {
        case 'lead':
          return <Text size="heading" weight="semibold">{runs(block.text)}</Text>
        case 'paragraph':
          return <Text>{runs(block.text)}</Text>
        case 'label':
          return <Text size="caption" color="subtle">{block.text}</Text>
        case 'list':
          return (
            <Box flexDirection="column">
              {block.items.map((item, index) => (
                <Text>{block.isOrdered && !item.startsWith('  ') ? `${index + 1}. ` : '• '}{runs(item.trim())}</Text>
              ))}
            </Box>
          )
        case 'code':
          return <Code source={block.source} language={block.language === '' ? 'text' : block.language} />
        case 'options':
          return (
            <Box flexDirection={isWide ? 'row' : 'column'} gap={1}>
              {block.options.map(option => (
                <Box flexDirection="column" flexGrow={1} borderStyle="round" borderColor={option.isLean ? 'success' : 'subtle'} paddingX={1}>
                  <Text weight="semibold">{option.title}</Text>
                  {option.isLean ? <Text size="caption" color="success">I lean here</Text> : null}
                  {option.subtitle === '' ? null : <Text size="caption" color="subtle">{option.subtitle}</Text>}
                  {option.points.map(point =>
                    point.isDownside ? <Text color="warning">• {point.text}</Text> : <Text>• {runs(point.text)}</Text>,
                  )}
                </Box>
              ))}
            </Box>
          )
        case 'ask':
          return (
            <Box flexDirection="column" borderStyle="round" borderColor="warning" paddingX={1}>
              <Text size="caption" color="warning">Your call</Text>
              <Text>{runs(block.text)}</Text>
            </Box>
          )
        case 'pending':
          return <Text>{block.text}</Text>
        case 'other':
          return <Markdown text={block.markdown} />
        case 'keep':
          return null
      }
    }

    return (
      <Box flexDirection="column" gap={1} {...(columns === undefined ? {} : { width: Math.min(columns, LINE_MAX) })}>
        {keep.length === 0 ? null : (
          <Box flexDirection="column" borderStyle="round" borderColor="success" paddingX={1}>
            <Text size="caption" color="success">Keep from this reply</Text>
            {keep.map((item, index) => (
              <Box flexDirection="row" gap={1}>
                <Text color="subtle">{item.label}</Text>
                <Text mono>{item.value}</Text>
                <Button key={`keep-copy-${index}`} label="Copy" onPress={press => { void $.ui.copy({ text: item.value, surface: press.surface }) }} />
              </Box>
            ))}
          </Box>
        )}
        {blocks.filter(block => block.kind !== 'keep').map(draw)}
      </Box>
    )
  }).catch(($, e, next) => next(e))
}

import type { MarginPin } from '../types'

export type ChatMessage = { role: 'user' | 'assistant'; text: string }
export type SearchHit = { text: string; where: string; copy: string }

export const SEARCH_LIMIT = 20
const WIDTH = 80

export const excerpt = (line: string, query: string, width = WIDTH): string => {
  const text = line.trim()
  if (text.length <= width) return text
  const at = Math.max(0, text.toLowerCase().indexOf(query.toLowerCase()))
  const start = Math.max(0, Math.min(at - Math.floor((width - query.length) / 2), text.length - width))
  return `${start > 0 ? '…' : ''}${text.slice(start, start + width)}${start + width < text.length ? '…' : ''}`
}

export const searchChat = (
  messages: readonly ChatMessage[],
  pins: readonly MarginPin[],
  query: string,
  limit = SEARCH_LIMIT,
): SearchHit[] => {
  const q = query.trim().toLowerCase()
  if (q === '') return []

  const hits: SearchHit[] = pins
    .filter(pin => (pin.secret ? pin.label : `${pin.label} ${pin.value}`).toLowerCase().includes(q))
    .map(pin => ({ text: `${pin.label}: ${pin.secret ? '••••' : pin.value}`, where: 'pin', copy: pin.value }))

  const counts = { user: 0, assistant: 0 }
  const numbered = messages.map(message => ({ ...message, n: (counts[message.role] += 1) }))
  for (const message of numbered.reverse()) {
    for (const line of message.text.split('\n')) {
      if (!line.toLowerCase().includes(q)) continue
      hits.push({ text: excerpt(line, q), where: `${message.role === 'assistant' ? 'reply' : 'you'} ${message.n}`, copy: line.trim() })
    }
  }
  return hits.slice(0, limit)
}
```

import { isOpenAtom, isPeekAtom, isStoreDownAtom, type On, PANE, pinsAtom, queryAtom, revealedAtom } from './state'

const keepPin = (pins: MarginPin[], id: string): MarginPin[] => pins.map(pin => (pin.id === id ? { ...pin, expiresAt: null } : pin))
const dropPin = (pins: MarginPin[], id: string): MarginPin[] => pins.filter(pin => pin.id !== id)

export const registerPane = (on: On): void => {
  // A tab that opened on its own for a new pin folds again once you send your next message.
  on('prompt.submit', async ($, e, next) => {
    if (await read($, isPeekAtom)) {
      await update($, isPeekAtom, () => false)
      await update($, isOpenAtom, () => false)
    }
    return next(e)
  })

  on('ui.render', { component: 'Pane', requestId: PANE }, async ($, e) => {
    const elements = $.ui.resolve(e)
    const { Box, Text, Button } = elements
    const now = await $.clock.now()
    const pins = (await read($, pinsAtom)).filter(pin => isLive(pin, now))

    if (!(await read($, isOpenAtom))) {
      return (
        <Box flexDirection="row">
          <Button key="open" plain label={`Pins ${pins.length}`} onPress={() => { void update($, isOpenAtom, () => true) }} />
        </Box>
      )
    }

    const query = await read($, queryAtom)
    const revealed = await read($, revealedAtom)
    const isStoreDown = await read($, isStoreDownAtom)
    const messages = query.trim() === '' ? [] : await $.session.messages()
    const hits = searchChat(Array.isArray(messages) ? messages : [], pins, query)

    return (
      <Box flexDirection="column" gap={1}>
        <Box flexDirection="row" gap={1}>
          <Text weight="semibold">Pins {pins.length}</Text>
          <Button key="fold" plain label="Fold" onPress={() => { void update($, isOpenAtom, () => false) }} />
        </Box>
        {'Input' in elements ? (
          <elements.Input
            key="q"
            placeholder="Search pins and this chat"
            value={query}
            onInput={value => { void update($, queryAtom, () => value) }}
            onSubmit={value => { void update($, queryAtom, () => value) }}
          />
        ) : null}
        {isStoreDown ? <Text size="caption" color="warning">Pins are kept for this chat only.</Text> : null}
        {query.trim() !== ''
          ? hits.length === 0
            ? <Text color="subtle">Nothing matches.</Text>
            : hits.map((hit, index) => (
                <Box flexDirection="row" gap={1}>
                  <Text size="caption" color="subtle">{hit.where}</Text>
                  <Text>{hit.text}</Text>
                  <Button key={`hit-${index}`} label="Copy" onPress={press => { void $.ui.copy({ text: hit.copy, surface: press.surface }) }} />
                </Box>
              ))
          : pins.length === 0
            ? <Text color="subtle">No pins yet. Use /pin to add one.</Text>
            : pins.map(pin => {
                const isHidden = pin.secret && !revealed.includes(pin.id)
                return (
                  <Box flexDirection="row" gap={1}>
                    <Text weight="medium">{pin.label}</Text>
                    <Text mono>{isHidden ? '••••' : pin.value}</Text>
                    {isHidden ? <Button key={`show-${pin.id}`} label="Show" onPress={() => { void update($, revealedAtom, ids => [...ids, pin.id]) }} /> : null}
                    <Button key={`copy-${pin.id}`} label="Copy" onPress={press => { void $.ui.copy({ text: pin.value, surface: press.surface }) }} />
                    {pin.expiresAt === null ? null : <Button key={`keep-${pin.id}`} label="Keep" onPress={() => { void savePins($, list => keepPin(list, pin.id)) }} />}
                    <Button key={`unpin-${pin.id}`} label="Unpin" onPress={() => { void savePins($, list => dropPin(list, pin.id)) }} />
                  </Box>
                )
              })}
      </Box>
    )
  })
}
```

```ts
import { read, update } from 'claude-code'

import { addItems, loadPins, type PinInput } from './pins'
import { setOff } from './settings'
import { type Engine, isOpenAtom, lastKeepAtom, type On, PANE } from './state'

const LABELLED = /^([^:]{1,24}):\s+(.+)$/

export const readPinArgs = (args: string): PinInput => {
  const labelled = LABELLED.exec(args.trim())
  return labelled
    ? { label: (labelled[1] ?? '').trim(), value: (labelled[2] ?? '').trim(), source: 'user' }
    : { label: 'Note', value: args.trim(), source: 'user' }
}

export const declareCommands = async ($: Engine): Promise<void> => {
  await $.command.register({ name: 'pin', description: "Pin text, or the last reply's keep items, to margin's Pins tab", argumentHint: '[Label: value]' })
  await $.command.register({ name: 'margin', description: "Open margin's Pins tab, or turn its reply drawing off or on", argumentHint: '[off|on]' })
}

export const registerCommands = (on: On): void => {
  on('command.run', { command: 'pin' }, async ($, e) => {
    if (e.args.trim() !== '') {
      const item = readPinArgs(e.args)
      await addItems($, [item], true)
      return { text: `Pinned "${item.label}".` }
    }
    const items = await read($, lastKeepAtom)
    if (items.length === 0) return { text: 'The last reply had nothing to keep. Try /pin Label: value.' }
    await addItems($, items, true)
    return { text: `Kept ${items.length} pins from the last reply.` }
  })

  on('command.run', { command: 'margin' }, async ($, e) => {
    const arg = e.args.trim().toLowerCase()
    if (arg === '') {
      await loadPins($)
      await update($, isOpenAtom, () => true)
      await $.ui.open({ id: PANE, title: 'Pins' })
      return { text: 'Pins tab opened.' }
    }
    if (arg === 'off') {
      await setOff($, true)
      return { text: 'margin is off: replies use the normal drawing and Claude gets no note. /margin on turns it back on.' }
    }
    if (arg === 'on') {
      await setOff($, false)
      return { text: 'margin is on.' }
    }
    return { text: 'Use /margin, /margin off or /margin on.' }
  })
}
```

# How margin works

Current truth for the `margin` mod. The design and its history: [the spec](superpowers/specs/2026-10-27-margin-design.md).

## Pieces

| File | Job |
| --- | --- |
| `hooks/register.tsx` | Wires everything. The one `session.start` hook: project folder, settings, pins, commands, and the Pins tab if the project has pins. |
| `hooks/note.ts` | Adds `NOTE` to the system prompt (`prompt.compose`, `scope: 'session'`) unless margin is off. |
| `hooks/blocks.ts` | Reads reply markdown into blocks. Open fences are `pending`; tables, HTML, quotes, three-level lists and unreadable `options` are `other`. |
| `hooks/reply.tsx` | Draws `AssistantMessage`. `other` goes to `Markdown`; a summary, margin off, or a throw goes to the normal drawing. |
| `hooks/keep.ts` | Keep items from the `keep` fence; with no fence, a `localhost:<port>` URL and a password value. Secrets dropped. |
| `hooks/secrets.ts` | Known key formats plus long high-entropy tokens. |
| `hooks/pins.ts` | Pin rules and the store. Key `pins:<project folder>`. The store is the source of truth on every save. |
| `hooks/turn.ts` | On `turn.complete` of the main thread: keep items to pins, and the first-pin peek. |
| `hooks/pane.tsx` | The Pins tab; folds on your next message after a peek. |
| `hooks/search.ts` | Pins first, then this chat newest first, 20 results. |
| `hooks/commands.ts` | `/pin` and `/margin`. |
| `hooks/settings.ts` | `/margin off` and `on`, store key `settings`. |

## Pin rules

- Same label (case-insensitive) replaces the old pin and keeps its id. `Note` pins match on label and value.
- Pins from Claude or the pattern check expire 24 hours after they were made; `/pin`, `/pin` alone and Keep make them permanent.
- A `/pin` value that looks like a key is stored with `secret: true` and drawn as `••••` until Show.

## Checking changes

`claude plugin validate .`, `claude plugin test .`, and `npx -y -p typescript@5.6.3 tsc -p .` with `.claude-plugin/types/` in place.
```

# margin for Claude Code

Readable replies, pins and chat search for Claude Code, made for the VS Code side panel.

![A reply drawn by margin](docs/images/reply.png)

- **Replies you can skim.** The answer first, short paragraphs, section labels, code as chips, choices as side-by-side cards, and the question you need to answer in its own box.
- **Keep from this reply.** URLs, test logins and commands from a reply land on a card with Copy buttons, and in the Pins tab.
- **Pins per project.** Every chat in the same folder sees the same pins. Pins Claude makes last a day; yours stay until you remove them.
- **Search.** Type in the Pins tab to search your pins and the whole current chat.

From a shell:
